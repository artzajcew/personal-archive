# Chronikle

## Минимальный запуск

Создайте виртуальное окружение и запустите API:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8001
```

Параметры PostgreSQL находятся в `DB_CONFIG` файла `database.py`. REST API доступен по адресу `http://127.0.0.1:8001`. Эндпоинт `GET /files` возвращает записи из таблицы `archive_items` PostgreSQL-базы.
Для фильтрации по пользователю используй `GET /files?user_id=1`.
Интерактивная документация доступна по адресу `http://127.0.0.1:8001/docs`.

## Назначение

Chronikle — веб-приложение для создания и организации личного цифрового архива. Система предназначена для удобного хранения, систематизации и поиска личных документов, фотографий, заметок и других цифровых материалов. Приложение позволяет пользователю хранить важную информацию в одном месте и получать к ней быстрый доступ.

## Целевая аудитория

Основная целевая аудитория — пользователи, которым необходимо централизованно хранить и упорядочивать личную информацию. Приложение подойдёт студентам, работающим специалистам и всем, кто хочет организовать собственное цифровое пространство.

## Предметная область

Предметная область проекта — управление личными цифровыми данными и электронными архивами. Она включает процессы добавления, хранения, распределения по папкам, редактирования, удаления и поиска цифровых материалов. Особое внимание уделяется удобной организации архива и быстрому доступу к сохранённой информации.

## Основные сущности

* **Пользователь (User)** — учётная запись пользователя системы.
* **Папка (Folder)** — раздел для группировки и структурирования архивных материалов.
* **Элемент архива (Archive Item)** — сохранённый документ, фотография, заметка или другой цифровой материал.
* **Тег (Tag)** — метка для дополнительной классификации и быстрого поиска материалов.

## Основные функции

* Регистрация и авторизация пользователей.
* Создание и управление папками.
* Добавление и загрузка материалов в личный архив.
* Перемещение материалов между папками.
* Добавление тегов для удобной классификации.
* Просмотр, редактирование и удаление материалов.
* Поиск и фильтрация материалов.
* Управление личными данными пользователя.
